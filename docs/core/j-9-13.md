# ENUMS

1. Why do we need enums?
Imagine our banking application supports three account types:
- Savings
- Current
- Business
One approach is to store these as strings:
String accountType = "SAVINGS";


But there's a problem:
String accountType = "SAVNGS"; // Typo


Java accepts this string. It doesn't know that "SAVNGS" is an invalid account type.

An enum solves this by defining a fixed set of allowed values.
2. First working demonstration
Create a file named AccountType.java inside corejava/oop.

package corejava.oop;

public enum AccountType {
    SAVINGS,
    CURRENT,
    BUSINESS
}



Notice: we use enum instead of class.

Now use it in BankAccountDemo.java:

package corejava.oop;

public class BankAccountDemo {

    public static void main(String[] args) {

        AccountType accountType = AccountType.SAVINGS;

        System.out.println(accountType);

        if (accountType == AccountType.SAVINGS) {
            System.out.println("Savings account selected");
        }
    }
}



Expected output:
SAVINGS
Savings account selected


3. What just happened?
AccountType accountType = AccountType.SAVINGS;


- AccountType is our enum type.
- accountType is the variable.
- AccountType.SAVINGS is one of the predefined constants.
Unlike a String, you cannot assign an arbitrary value:
AccountType accountType = "SAVINGS"; // Compilation error


You must use one of the declared enum constants.
4. Useful enum features
Get all available values:
for (AccountType type : AccountType.values()) {
    System.out.println(type);
}


Output:
SAVINGS
CURRENT
BUSINESS


Convert a String into an enum:
AccountType type = AccountType.valueOf("CURRENT");

System.out.println(type);


valueOf() requires an exact matching enum name; otherwise it throws IllegalArgumentException.

Use enum with switch:
switch (accountType) {
    case SAVINGS:
        System.out.println("Savings account");
        break;

    case CURRENT:
        System.out.println("Current account");
        break;

    case BUSINESS:
        System.out.println("Business account");
        break;
}
