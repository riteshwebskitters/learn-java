# J-13.1 — Functional Interfaces

A functional interface is an interface that contains exactly one abstract method.

Example:
package corejava.engineering.functional;

@FunctionalInterface
public interface TransactionValidator {

    boolean isValid(int amount);

}


Let's understand the important parts:
- interface: Defines a contract.
- isValid(int amount): The single abstract method.
- boolean: The method's return type.
- @FunctionalInterface: Tells the compiler that this interface is intended to have exactly one abstract method.
Why does this matter?

Because Java can use this interface as the target type for a lambda expression.
Without a lambda
TransactionValidator validator = new TransactionValidator() {
    @Override
    public boolean isValid(int amount) {
        return amount > 0;
    }
};


With a lambda
TransactionValidator validator = amount -> amount > 0;


Both implementations do the same thing.

The lambda provides the implementation of isValid() without requiring you to write the anonymous class.
Using the implementation
public class TransactionValidatorDemo {

    public static void main(String[] args) {

        TransactionValidator validator = amount -> amount > 0;

        System.out.println(validator.isValid(500));
        System.out.println(validator.isValid(-100));

    }
}


Output:
true
false


Notice that we still call validator.isValid(). The lambda doesn't remove the interface or its method. It simply provides a shorter implementation.
