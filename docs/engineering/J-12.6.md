J-12.6 — Map and HashMap
So far, we've stored individual values in collections.

But backend applications frequently need to store data as key-value pairs.

For example, imagine a transaction system:
Transaction ID (Key)	Amount (Value)
TXN1001	2500
TXN1002	4500
TXN1003	1200

Instead of searching through a list of transactions, we can retrieve a transaction amount using its ID.

That's where Map comes in.

Basic example:
import java.util.HashMap;
import java.util.Map;

public class TransactionRegistry {
    public static void main(String[] args) {

        Map<String, Integer> transactions = new HashMap<>();

        transactions.put("TXN1001", 2500);
        transactions.put("TXN1002", 4500);
        transactions.put("TXN1003", 1200);

        System.out.println(transactions);

        System.out.println(
            "TXN1001 Amount: " + transactions.get("TXN1001")
        );
    }
}


Output:
{TXN1001=2500, TXN1002=4500, TXN1003=1200}
TXN1001 Amount: 2500


Before the exercise, understand these five methods
Method	Purpose
put(key, value)	Add or update an entry
get(key)	Retrieve value using key
containsKey(key)	Check whether key exists
remove(key)	Remove an entry
size()	Get number of entries

Important concept: A Map does not allow duplicate keys. If you insert an existing key again, its value gets replaced.
