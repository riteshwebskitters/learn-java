# J-12 — Java Collections Framework

This is an important chapter for backend development. You'll use collections constantly when building Spring Boot services, processing API requests, managing transactions, and working with database results.
1. Why do we need Collections?
So far, we've used arrays:
int[] transactionAmounts = {1000, 2000, 3000};


Arrays have limitations:
- Fixed size after creation.
- Limited built-in operations.
- Managing insertion, deletion, and searching requires additional logic.
Collections provide flexible data structures with built-in operations.

For example:
List<Integer> transactionAmounts = new ArrayList<>();

transactionAmounts.add(1000);
transactionAmounts.add(2000);
transactionAmounts.add(3000);

System.out.println(transactionAmounts);


Output:
[1000, 2000, 3000]


Notice that we can add elements without defining the size beforehand.

3. J-12.1 — List interface and ArrayList
A List maintains insertion order and allows duplicate values.

Let's start with ArrayList, one of the most commonly used collection implementations.
package corejava.engineering.collections;

import java.util.ArrayList;
import java.util.List;

public class TransactionList {
    public static void main(String[] args) {

        List<Integer> transactions = new ArrayList<>();

        transactions.add(1000);
        transactions.add(2500);
        transactions.add(3500);

        System.out.println(transactions);
        System.out.println("First transaction: " + transactions.get(0));
        System.out.println("Total transactions: " + transactions.size());
    }
}


Understand these methods
Method	Purpose
add()	Insert an element
get(index)	Retrieve an element
set(index, value)	Replace an element
remove(index)	Remove by index
remove(value)	Remove by value
size()	Get the number of elements
contains(value)	Check whether an element exists
isEmpty()	Check whether the list is empty
clear()	Remove all elements
