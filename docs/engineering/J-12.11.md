# J-12.11 — Collection Iteration

Now we need to learn how to traverse collections.

In backend applications, you frequently need to:
- Process transaction records.
- Calculate total transaction amounts.
- Find failed transactions.
- Generate reports.
- Validate records.
Java provides several ways to iterate over collections.
Method 1 — Enhanced for loop
List<String> transactions = List.of(
    "TXN1001",
    "TXN1002",
    "TXN1003"
);

for (String transaction : transactions) {
    System.out.println(transaction);
}


This is the simplest approach when you only need to read each element.
Method 2 — Iterator
List<String> transactions = new ArrayList<>();

transactions.add("TXN1001");
transactions.add("TXN1002");
transactions.add("TXN1003");

Iterator<String> iterator = transactions.iterator();

while (iterator.hasNext()) {
    String transaction = iterator.next();
    System.out.println(transaction);
}


Understand these three methods:
Method	Purpose
iterator()	Creates an iterator
hasNext()	Checks whether another element exists
next()	Returns the next element

Important: If you want to remove elements safely while iterating, use iterator.remove() rather than directly modifying the collection inside an enhanced for loop.
Method 3 — forEach
transactions.forEach(transaction -> {
    System.out.println(transaction);
});


We'll study lambda expressions properly in the functional programming section. For now, understand that forEach() executes an action for each element.
