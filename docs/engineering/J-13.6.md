# J-13.6 Method References

J-13.6.1 — Static Method References
Now let's understand the first major category of method references.

A static method belongs to a class rather than an individual object.

Suppose we have a utility class:
package corejava.engineering.functional;

public class TransactionUtils {

    public static boolean isValidAmount(int amount) {
        return amount > 0;
    }
}


We can reference this static method directly:
Predicate<Integer> validator = TransactionUtils::isValidAmount;


Compare the two approaches:
Lambda	Method reference
amount -> TransactionUtils.isValidAmount(amount)	TransactionUtils::isValidAmount

Both do exactly the same thing.

Notice the syntax:

ClassName::staticMethodName


## J-13.6.2 — Instance Method References
Now we'll look at a different situation.

A static method belongs to a class. An instance method belongs to an object.

Suppose we have a transaction logger:
package corejava.engineering.functional;

public class TransactionLogger {

    public void log(String transactionId) {
        System.out.println("Transaction processed: " + transactionId);
    }
}


First, the lambda approach:
TransactionLogger logger = new TransactionLogger();

Consumer<String> lambdaLogger =
        transactionId -> logger.log(transactionId);


Now the method reference:
Consumer<String> methodLogger = logger::log;


Notice the difference:
Static method	Instance method
TransactionUtils::isValidAmount	logger::log
Class name	Object reference
ClassName::methodName	objectName::methodName

The instance method reference uses an existing object.


#J-13.6.3 — Arbitrary Object Instance Method References
This category looks a little different.

Previously, we referenced a method belonging to an already-created object:
logger::log


Now, Java can reference an instance method of an arbitrary object of a particular type.

Let's use transaction sorting as an example.

Suppose we have:
List<String> transactionIds = List.of(
        "txn300",
        "txn100",
        "txn200"
);


We want to convert every transaction ID to uppercase.

Lambda approach:
transactionIds.stream()
        .map(transactionId -> transactionId.toUpperCase())
        .forEach(System.out::println);


Method reference approach:
transactionIds.stream()
        .map(String::toUpperCase)
        .forEach(System.out::println);


Output:
TXN300
TXN100
TXN200


How does String::toUpperCase work?
Here:
- String is the type of object.
- toUpperCase() is an instance method.
- Each String in the stream becomes the object on which the method is invoked.
Conceptually, Java performs:
transactionId -> transactionId.toUpperCase()


This method-reference category is called an unbound instance method reference.

Notice the distinction:
Category	Syntax	Meaning
Particular object	logger::log	Use an existing object
Arbitrary object	String::toUpperCase	Invoke the method on each supplied object
