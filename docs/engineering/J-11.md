J-11 — Wrapper Classes and Autoboxing
Phase 3 · Core Java Engineering

Now we're moving into a concept that becomes particularly important when working with Java Collections, generics, and Spring Boot.
1. Why do wrapper classes exist?
Java has eight primitive data types:
Primitive	Wrapper class
byte	Byte
short	Short
int	Integer
long	Long
float	Float
double	Double
char	Character
boolean	Boolean

A primitive stores a basic value.

A wrapper class represents that value as an object.

For example:
int balance = 5000;

Integer accountBalance = 5000;


Here:
- balance is a primitive int.
- accountBalance is an Integer object.
2. Why do we need wrapper objects?
Consider this:
ArrayList<int> transactions = new ArrayList<>();


This is invalid Java.

Why?

Java Collections work with objects, not primitive types.

Instead, we write:
ArrayList<Integer> transactions = new ArrayList<>();


This is one of the most important reasons wrapper classes exist.

We'll explore Collections in detail later.
3. Autoboxing and unboxing
Java can automatically convert between primitives and their corresponding wrapper objects.

Autoboxing: Primitive → Wrapper object.
int amount = 5000;

Integer transactionAmount = amount;


Unboxing: Wrapper object → Primitive.
Integer transactionAmount = 5000;

int amount = transactionAmount;


Java handles these conversions automatically.
Conversion overview
Autoboxing
int
Integer

Unboxing
Integer
int



4. Demonstration
Create WrapperDemo.java inside:

corejava/engineering/
package corejava.engineering;

public class WrapperDemo {

    public static void main(String[] args) {

        // Primitive
        int balance = 5000;

        // Autoboxing
        Integer accountBalance = balance;

        System.out.println("Primitive balance: " + balance);
        System.out.println("Wrapper balance: " + accountBalance);

        // Unboxing
        int updatedBalance = accountBalance;

        System.out.println("Unboxed balance: " + updatedBalance);

        // Wrapper utility method
        String transactionAmount = "2500";

        int amount = Integer.parseInt(transactionAmount);

        System.out.println("Parsed transaction amount: " + amount);
    }
}


Expected output:
Primitive balance: 5000
Wrapper balance: 5000
Unboxed balance: 5000
Parsed transaction amount: 2500


Notice this line:
int amount = Integer.parseInt(transactionAmount);


parseInt() converts a numeric String into a primitive int.

Compare it with:
Integer amount = Integer.valueOf(transactionAmount);


valueOf() returns an Integer object.
