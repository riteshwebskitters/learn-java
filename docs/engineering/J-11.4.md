J-11.4 — Generic Methods
Now let's learn something slightly different.

A generic class makes the entire class work with a type parameter.

A generic method allows an individual method to work with different types, even if its containing class is not generic.
Example
public class TransactionUtility {

    public static <T> void displayTransaction(T transactionData) {
        System.out.println("Transaction: " + transactionData);
    }

    public static void main(String[] args) {

        displayTransaction(7500);
        displayTransaction("SUCCESS");
        displayTransaction(2500.75);
    }
}


Output:
Transaction: 7500
Transaction: SUCCESS
Transaction: 2500.75


Understand this syntax
public static <T> void displayTransaction(T transactionData)


Part	Meaning
public	Accessible from other classes
static	Can be called without creating an object
<T>	Declares a method-level type parameter
void	Doesn't return a value
T transactionData	Accepts a value of the inferred type

Notice that <T> appears before the return type (void).

This is how Java identifies a generic method.
