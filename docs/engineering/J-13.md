# J-13 — Lambda Expressions and Functional Interfaces

What are we learning, and why?
In Java, we often pass behavior as well as data.

For example, imagine you have a list of transactions and want to print each transaction, validate its amount, or calculate a fee.

Before lambdas, Java commonly used anonymous classes to pass behavior. Lambdas make this much shorter and easier to read.

We'll learn the concepts in this order:
1. Functional interfaces
2. The @FunctionalInterface annotation
3. Lambda expression syntax
4. Built-in functional interfaces: Predicate, Function, Consumer, Supplier
5. BiFunction, BiPredicate, and BiConsumer
6. Method references
7. Practical transaction-processing exercises
