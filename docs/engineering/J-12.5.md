# J-12.5 — TreeSet
TreeSet stores unique elements in sorted order.

For example:
Set<Integer> amounts = new TreeSet<>();

amounts.add(5000);
amounts.add(1000);
amounts.add(3000);
amounts.add(2000);
amounts.add(1000);

System.out.println(amounts);


Output:
[1000, 2000, 3000, 5000]


Notice:
- Duplicate 1000 is ignored.
- Elements are automatically sorted in ascending order.
- Unlike HashSet and LinkedHashSet, TreeSet generally has O(log n) add, remove, and search operations.
