J-10.8 — Custom Exceptions
So far, we've used Java's built-in exceptions:
- IllegalArgumentException
- ArithmeticException
- NumberFormatException
But consider a banking application.

Would this message be sufficiently descriptive?
IllegalArgumentException: Insufficient balance


It works, but as the application grows, we may want a dedicated exception representing a specific business failure.

For example:
InsufficientBalanceException
InvalidTransactionException
AccountInactiveException
PaymentDeclinedException


These are called custom exceptions.
Step 1 — Create your first custom exception
Create InsufficientBalanceException.java.
package corejava.engineering.exceptions;

public class InsufficientBalanceException extends RuntimeException {

    public InsufficientBalanceException(String message) {
        super(message);
    }
}


Let's understand the important parts:
extends RuntimeException


This makes our custom exception unchecked.
super(message);


This passes the message to the parent RuntimeException constructor.

Java's exception infrastructure can then expose that message through:
exception.getMessage();


Step 2 — Use the custom exception
Create CustomExceptionDemo.java.
package corejava.engineering.exceptions;

public class CustomExceptionDemo {

    public static void withdraw(int balance, int amount) {

        if (amount <= 0) {
            throw new IllegalArgumentException("Invalid withdrawal amount");
        }

        if (amount > balance) {
            throw new InsufficientBalanceException("Insufficient account balance");
        }

        System.out.println("Withdrawal successful");
        System.out.println("Remaining balance: " + (balance - amount));
    }

    public static void main(String[] args) {

        try {
            withdraw(5000, 7000);

        } catch (InsufficientBalanceException exception) {

            System.out.println("Banking error: " + exception.getMessage());

        } catch (IllegalArgumentException exception) {

            System.out.println("Validation error: " + exception.getMessage());
        }
    }
}


Expected output:
Banking error: Insufficient account balance


Notice that we now distinguish between two types of failures:
Exception	Meaning
IllegalArgumentException	Invalid withdrawal input
InsufficientBalanceException	Valid positive amount, but insufficient funds

This makes the business logic more expressive.
