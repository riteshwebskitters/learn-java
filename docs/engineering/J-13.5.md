# J-13.5 — BiFunctional Interfaces


Previously, we learned functional interfaces that generally accept one input.

Now we'll learn interfaces that accept two inputs.

The three interfaces are:
1. BiFunction<T, U, R>
2. BiPredicate<T, U>
3. BiConsumer<T, U>
1. BiFunction — two inputs, one output
Input 1 + Input 2 → Output
Imagine calculating a transaction fee based on an amount and a fee percentage.
import java.util.function.BiFunction;

BiFunction<Double, Double, Double> calculateFee =
        (amount, percentage) -> amount * percentage / 100;

Double fee = calculateFee.apply(5000.0, 2.0);

System.out.println("Fee: " + fee);


Output:
Fee: 100.0


Understand the generic types:
BiFunction<Double, Double, Double>


Generic	Meaning
First Double	First input: amount
Second Double	Second input: percentage
Third Double	Return type: calculated fee

The method used to execute it is apply().
Another practical example
Calculate the remaining wallet balance after a withdrawal:
BiFunction<Double, Double, Double> calculateBalance =
        (balance, withdrawal) -> balance - withdrawal;

System.out.println(calculateBalance.apply(10000.0, 2500.0));


Result: 7500.0.

2. BiPredicate — two inputs, boolean output
Input 1 + Input 2 → boolean
Imagine validating whether a wallet has enough balance for a withdrawal.
import java.util.function.BiPredicate;

BiPredicate<Double, Double> hasSufficientBalance =
        (balance, withdrawal) -> balance >= withdrawal;

System.out.println(hasSufficientBalance.test(10000.0, 2500.0));
System.out.println(hasSufficientBalance.test(1000.0, 2500.0));


Output:
true
false


The two generic types represent the two input types. The result is always boolean.

The method used is test().

3. BiConsumer — two inputs, no return
Input 1 + Input 2 → No output
Imagine logging a transaction ID and its amount together.
import java.util.function.BiConsumer;

BiConsumer<String, Double> transactionLogger =
        (transactionId, amount) ->
                System.out.println("Transaction: " + transactionId + " | Amount: " + amount);

transactionLogger.accept("TXN1001", 5000.0);


Output:
Transaction: TXN1001 | Amount: 5000.0


The method used is accept().

Quick comparison
Interface	Inputs	Returns	Execution method
BiFunction<T,U,R>	2	Value	apply()
BiPredicate<T,U>	2	Boolean	test()
BiConsumer<T,U>	2	Nothing	accept()
