J-13.2 — Understanding Lambda Syntax
Before introducing built-in interfaces, let's understand the syntax.

A lambda has this general structure:
(parameters) -> expression


There are three common variations:

1. One parameter — parentheses optional
amount -> amount > 0


2. Multiple parameters — parentheses required
(amount, fee) -> amount + fee


3. Multiple statements — use curly braces and an explicit return when needed
amount -> {
    int fee = 20;
    return amount > fee;
}


The return statement is required here because this block lambda must return a boolean.
