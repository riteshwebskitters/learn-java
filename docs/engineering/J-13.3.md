# J-13.3 — Built-in Functional Interfaces

So far, you've created your own functional interfaces:
- TransactionValidator
- TransactionCalculator
Java already provides commonly used functional interfaces, so we don't need to create a custom interface every time.

These are available in the java.util.function package.

We'll focus on four important interfaces first.
1. Predicate — test a condition
Input → boolean
A Predicate accepts a value and returns true or false.
import java.util.function.Predicate;

Predicate<Integer> isValidAmount = amount -> amount > 0;

System.out.println(isValidAmount.test(2500)); // true
System.out.println(isValidAmount.test(-100)); // false


Important: Predicate uses the test() method.

Practical use cases:
- Validate transaction amounts.
- Check whether an account is active.
- Check whether a transaction exceeds a limit.
2. Function — transform a value
Input → Output
A Function accepts one value and returns another value. The input and output types can differ.
import java.util.function.Function;

Function<Integer, Double> calculateFee =
        amount -> amount * 0.02;

System.out.println(calculateFee.apply(2500)); // 50.0


Here:
- Integer = input type.
- Double = return type.
- apply() = method used to execute the function.
3. Consumer — consume a value
Input → No return
A Consumer accepts a value and performs an operation without returning a result.
import java.util.function.Consumer;

Consumer<String> transactionLogger =
        transactionId -> System.out.println("Processed: " + transactionId);

transactionLogger.accept("TXN1001");


The method is accept().

Practical use cases:
- Logging transactions.
- Printing transaction details.
- Sending notifications.
4. Supplier — supply a value
No input → Output
A Supplier takes no arguments and returns a value.
import java.util.function.Supplier;

Supplier<String> transactionIdGenerator =
        () -> "TXN-" + System.currentTimeMillis();

System.out.println(transactionIdGenerator.get());


The method is get().

Practical use cases:
- Generate transaction IDs.
- Supply default values.
- Provide timestamps.

Quick comparison
Interface	Input	Output	Method
Predicate<T>	Yes	Boolean	test()
Function<T,R>	Yes	Yes	apply()
Consumer<T>	Yes	No	accept()
Supplier<T>	No	Yes	get()
