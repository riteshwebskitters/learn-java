# J-12.2 — LinkedList
We've already learned ArrayList. Now we'll understand another implementation of the List interface: LinkedList.
1. What is LinkedList?
An ArrayList internally uses a resizable array.

A LinkedList uses a doubly linked list.

Each element is stored inside a node containing:
- The actual data.
- A reference to the previous node.
- A reference to the next node.

For example:
HEAD
  |
  v
[1000] <-> [2500] <-> [1500] <-> [4000]
                                      |
                                      v
                                     TAIL


Each node connects to its previous and next node.
2. ArrayList vs LinkedList
Operation	ArrayList	LinkedList
Internal structure	Dynamic array	Doubly linked list
Access by index	Fast — O(1)	Slower — O(n)
Add at end	Usually O(1) amortized	O(1)
Add/remove at beginning	O(n)	O(1)
Insert/remove in middle	O(n)	O(n) to locate, O(1) to relink
Memory usage	Generally lower	Higher due to node references

Important: LinkedList is not automatically faster for insertion and deletion. If you need to locate an element by index first, that traversal still costs time.
3. Basic LinkedList implementation
package corejava.engineering.collection;

import java.util.LinkedList;
import java.util.List;

public class TransactionLinkedList {

    public static void main(String[] args) {

        List<Integer> transactions = new LinkedList<>();

        transactions.add(1000);
        transactions.add(2000);
        transactions.add(3000);

        System.out.println(transactions);

        transactions.add(0, 500);

        System.out.println("After adding at beginning: " + transactions);

        transactions.remove(0);

        System.out.println("After removing first element: " + transactions);
    }
}


Notice something important:

We declared the variable as List<Integer>, but instantiated it using new LinkedList<>().

This is the same interface-based programming principle we just learned.
4. LinkedList-specific methods
Unlike ArrayList, LinkedList also implements the Deque interface, so it provides methods for working at both ends.
Method	Purpose
addFirst()	Insert at beginning
addLast()	Insert at end
getFirst()	Retrieve first element
getLast()	Retrieve last element
removeFirst()	Remove first element
removeLast()	Remove last element
peek()	Retrieve first element without removing
poll()	Retrieve and remove first element

These methods are useful when implementing queues and deques.
